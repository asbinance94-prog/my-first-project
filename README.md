# رشيز — رادار أخبار الذكاء الاصطناعي

موقع ثابت يسحب فيدات RSS كل ٣٠ دقيقة على GitHub Actions، يترجمها ويرتّبها عبر Claude API، ويكتب `data/news.json` الذي تقرأه الواجهة. بلا خادم، بلا قاعدة بيانات، بلا تكلفة استضافة.

---

## التشغيل — سبع خطوات

**١. أنشئي المستودع**

مستودع جديد على GitHub باسم `ai-radar`. ارفعي كل الملفات. الخصوصية: عام أو خاص، كلاهما يعمل (Pages يتطلب حساب Pro للمستودعات الخاصة).

**٢. افحصي المصادر — لا تتخطي هذه**

```bash
pip install -r requirements.txt
python validate_feeds.py
```

يقرأ `sources.json` ويكتب `validated_sources.json` + `validation_report.md`. افتحي التقرير. أي رابط فاشل: صحّحيه أو احذفيه. **لا تشحني قبل أن تعرفي كم مصدراً يعمل فعلاً.**

**٣. ابدئي بثمانية مصادر فقط**

احذفي الباقي من `validated_sources.json`. الأربعة الإبداعية الأعلى وزناً، و MarkTechPost، و MIT Technology Review، و One Useful Thing، و Bilawal Sidhu. وسّعي بعد أسبوعين لو نجحت.

**٤. المفتاح**

Settings ← Secrets and variables ← Actions ← New repository secret

الاسم: `ANTHROPIC_API_KEY`

**لا يوضع المفتاح في أي ملف داخل المستودع إطلاقاً.**

**٥. Pages**

Settings ← Pages ← Source: Deploy from a branch ← `main` / `(root)`

**٦. أول تشغيل يدوي**

Actions ← "تحديث رادار الأخبار" ← Run workflow. راقبي السجل. لو نجح، سيظهر commit جديد في `data/`.

**٧. افتحي الرابط**

`https://<اسمك>.github.io/ai-radar/` — ضيفيه لشاشة جوالك الرئيسية.

## التكلفة

الاستضافة والتشغيل: **صفر**. GitHub Actions مجاني للمستودعات العامة، والحصة المجانية للخاصة أكثر من كافية لهذا الحجم.

Claude API: مبني على افتراضات — **راجعي الأسعار الحالية بنفسك، فهي تتغير**.

| الافتراض | القيمة |
|---|---|
| أخبار جديدة يومياً بعد الدمج | ٤٠ عنقود |
| حجم الدفعة | ١٢ |
| استدعاءات يومياً | ~٤ |
| مدخلات لكل استدعاء | ~٦٠٠٠ توكن |
| مخرجات لكل استدعاء | ~٢٠٠٠ توكن |

بأسعار Sonnet المستخدمة في `enrich.py` (٣$ و ١٥$ لكل مليون) الناتج **أقل من ٠.٢٠$ يومياً** — أي أقل من ٦$ شهرياً في أسوأ الأحوال.

الحواجز مبنية في الكود:
- `DAILY_BUDGET_USD = 0.60` في `enrich.py` — عند التجاوز يتوقف الإثراء وتُكتب الأخبار خاماً بدل أن تُفقد.
- `MAX_TOTAL = 60` في `fetch.py` — سقف عناصر لكل تشغيل.
- طلبات مشروطة (`ETag` / `If-Modified-Since`) — الفيد الذي لم يتغيّر لا يُحمّل ولا يُعالَج.
- بصمات في `data/seen.json` — كل خبر يُترجم مرة واحدة في حياته.

راقبي `data/health.json` أول أسبوع. فيه الإنفاق اليومي وسجل آخر مئة تشغيل.

## ما جرى اختباره فعلياً

اختبارات حقيقية شُغّلت على بيانات مُصطنعة، كلها نجحت:

| ما اختُبر | النتيجة |
|---|---|
| تحليل RSS، تنظيف HTML، استخراج التوقيت | نجح |
| استبعاد العناصر الأقدم من ٤ أيام | نجح |
| فيد مكسور (HTML بدل XML) لا يرفع استثناء | نجح |
| البصمة: عنوان شبه متطابق + نفس الدومين = نفس البصمة | نجح |
| العنقدة: خبر واحد من ٣ مصادر صار عنقوداً واحداً | نجح |
| ممثل العنقود هو الأعلى وزناً | نجح |
| الأخبار المستقلة لم تُدمج خطأً | نجح |
| استخراج JSON من ردود ملفوفة بـ markdown أو نص | نجح |
| فشل دفعة لا يُفقد الأخبار — تسقط على fallback | نجح |
| حاجز الميزانية يوقف الإثراء ويحفظ الأخبار خاماً | نجح |
| مضاعف نماذج الفيديو والصورة يرفع الترتيب | نجح |
| عقد البيانات بين `news.json` و `index.html` مطابق | نجح |

```bash
python tests/make_fixtures.py
python tests/test_pipeline.py
python tests/test_enrich.py
```

**ما لم يُختبر:** الاتصال الفعلي بـ Claude API (لا مفتاح متاح أثناء البناء)، السحب من الإنترنت الحقيقي، وتشغيل GitHub Actions. هذه الثلاثة تتأكد منها في أول تشغيل يدوي.

## البنية

```
fetch.py    ← validated_sources.json   → data/raw_new.json
enrich.py   ← data/raw_new.json        → data/news.json + data/health.json
index.html  ← data/news.json
```

كل مرحلة تقرأ ملفاً وتكتب ملفاً. تقدرين تشغّلين أي مرحلة وحدها لتشخيص خلل.

**العنقدة تتم في بايثون لا في النموذج** — تشابه Jaccard على عناوين مُطبّعة بعتبة `0.45`. حتمية، مجانية، قابلة للاختبار، ولا تتأثر بتقلب النموذج. لو دمجت أخباراً مختلفة، ارفعي العتبة إلى `0.55`. لو فوّتت أخباراً مكررة، أنزليها إلى `0.38`.

## المعايرة — أول أسبوعين

نظام النقاط سيكون خاطئاً في البداية. هذا متوقع.

- لو تصدّرت أخبار التمويل: أنزلي وصف `business` في البرومبت إلى `1-2`.
- لو ضاعت أخبار الأدوات: ارفعي `weight` لمصادرها في `sources.json`.
- لو ظهرت أخبار مكررة: ارفعي عتبة `cluster()`.
- لو الملخصات ركيكة: عدّلي `SYSTEM` في `enrich.py` — هو النص الوحيد الذي يحكم جودة العربية.

**لا تبني إشعارات فورية قبل انتهاء المعايرة.** ستُزعجك بأخبار تافهة وتسكت عن المهم، وستهجرين النظام.

---

## حدود معروفة

- **X غير مغطّى.** لا يوجد وصول مجاني. الحل في `x_accounts.json`: التقاط النسخ البديلة (مدونة/يوتيوب) + قائمة X يدوية.
- **أدواتك الأساسية بلا فيدات.** Higgsfield و Seedance و Kling و Midjourney لا توفر RSS. اللوحة تفوّتها. لا حل تقني نظيف — تبقى متابعة يدوية.
- **The Batch و Import AI و Anthropic بلا RSS.** تحتاج مسار البريد (مرحلة لاحقة عبر Gmail API).
- **الحد الأدنى للتحديث ٣٠ دقيقة.** جدولة GitHub Actions غير دقيقة وقد تتأخر عند ضغط المنصة. "أول بأول" هنا تعني نصف ساعة لا لحظياً.

# الإضافات الثلاث

## ١. مسار البريد — `email_fetch.py`

يغطي النشرات بلا RSS: The Batch، Import AI، Anthropic News، The Rundown، Superhuman، Ben's Bites.

**IMAP لا Gmail API.** السبب: IMAP يحتاج كلمة مرور تطبيق واحدة، بينما Gmail API يحتاج OAuth ورموز تحديث وملف اعتماد داخل الـ workflow. أصغر حل ينجح.

الإعداد مرة واحدة:

1. فعّلي التحقق بخطوتين في حساب Google
2. أنشئي App Password من `myaccount.google.com/apppasswords`
3. اشتركي في النشرات، وأنشئي فلتر Gmail يضعها تحت ليبل `AI-Newsletters`
4. أضيفي في GitHub Secrets: `MAIL_USER` و `MAIL_PASSWORD` و `MAIL_FOLDER`

الأهم: **كل عدد يُفكَّك إلى قصص منفصلة** بدل أن يدخل كخبر واحد. قصة الـ Rundown عن Seedance تندمج تلقائياً مع خبر الـ RSS في نفس العنقود، فلا تقرئينها مرتين. البرومبت يتجاهل الإعلانات والرعايات وروابط الاشتراك.

ميزانية منفصلة: `BUDGET_USD = 0.25` في `email_fetch.py`.

## ٢. رصد الصفحات — `watch_pages.py`

**اقرئي هذا قبل الاعتماد عليه: هذه أضعف حلقة في النظام.**

يراقب Higgsfield و Kling و Midjourney و HeyGen و Luma. يستخرج الأسطر التي تشبه إعلانات الإصدار (رقم إصدار، أو launch / introducing / update) ويقارنها بما رآه سابقاً. الجديد فقط يصير خبراً، ويحمل شارة حمراء **"رصد صفحة — غير مؤكد"**.

المشكلة البنيوية: أغلب هذه المواقع تطبيقات JavaScript تُبنى في المتصفح، والطلب البسيط يرجّع هيكلاً فارغاً. السكربت **يكتشف هذه الحالة ويبلّغك بها** في `data/watch_report.md` بدل أن يصمت.

عند ظهور صفحات في التقرير، أمامك خياران:

- **الأرخص (موصى به):** احذفيها من `TARGETS` وتابعيها عبر Reddit. `r/StableDiffusion` و `r/aivideo` يغطيان هذه الإصدارات خلال ساعات، وهما فيدان حقيقيان ومستقران.
- **الأثقل:** أضيفي Playwright في الـ workflow واستبدلي `requests.get` بجلسة متصفح. يضيف حوالي ٩٠ ثانية لكل تشغيل.

التشغيل الأول لكل صفحة **لا ينتج أخباراً** — يبني الخط المرجعي فقط. هذا مقصود، وإلا لأغرقتك الصفحة بمحتواها كله كأخبار.

## ٣. المصادر العربية — `sources_ar.json`

ستة مصادر بوزن منخفض عمداً، في تبويب منفصل، **ومستبعدة من قسم "الأهم الآن"**.

السبب: المصادر العربية في التقنية تشتقّ من الإنجليزية بتأخير يوم إلى ثلاثة. لو دخلت المنافسة العادية لأزاحت الأصل بخبر مترجم متأخر. `score()` يضربها في `0.25`.

**قيمتها ليست السبق.** السؤال الذي تجيب عليه: ما الذي وصل جمهوري فعلاً؟ افتحي التبويب مرة أسبوعياً لا يومياً.

قيد معروف: المواقع العربية تعرّب الأسماء — "أنثروبيك" و"كلود" و"غوغل ديب مايند". العنقدة تعتمد على تشابه نصي، فخبر عربي عن Seedance مكتوب "سيدانس" **لن يندمج** مع الخبر الإنجليزي. النتيجة تكرار محتمل بين المسارين. مقبول لأن المسارين منفصلان بصرياً.
