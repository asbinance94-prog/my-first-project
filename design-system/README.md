نظام تصميم كامل لحساب @teachkw.ai على انستغرام: أبيض هادئ + أزرق واحد + خط أسود سميك (Cairo Black) للعناوين.

## كيف تصدّر منشور فعلي (PNG)

1. افتح أي ملف HTML في المتصفح (Chrome يعطي أدق نتيجة).
2. افتح أدوات المطوّر (F12) → في التبويب Elements حدد أي عنصر بكلاس `canvas`.
3. كليك يمين على العنصر في شجرة الـ HTML → **Capture node screenshot**.
   ستنزل صورة PNG بمقاسها الحقيقي (1080×1350 أو 1080×1080 أو 1080×1920) جاهزة للرفع مباشرة.

بديل أسرع: انسخ الملف الذي تبيه، عدّل النص داخل كل `<div class="canvas ...">` مباشرة، ثم كرر خطوة اللقطة.

## تعديل النصوص لمنشور جديد

كل شريحة/منشور مستقل داخل `<div class="canvas ...">...</div>`. غيّر النص فقط — لا تغيّر أسماء الكلاسات
(`headline`, `sub`, `fix-box`, إلخ) حتى يبقى التنسيق والمسافات كما هي تلقائيًا.

- العنوان الكبير دائمًا داخل كلاس يحتوي `headline`.
- التلوين الأزرق للشعار محصور بـ `.dot-ai` — لا تلوّن أي نص آخر.
- الخلفية الغامقة (`Blue Deep`) تُضاف بإضافة كلاس `dark` على عنصر الـ `canvas` نفسه.
