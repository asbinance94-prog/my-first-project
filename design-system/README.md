# هوية teachkw.ai البصرية

نظام تصميم كامل لحساب @teachkw.ai على انستغرام: أبيض هادئ + أزرق واحد + خط أسود سميك (Cairo Black) للعناوين.

| `carousel-prompt-mistakes.html` | كاروسيل جاهز من ٥ شرائح: "٣ أخطاء تسرق نتائج الذكاء الاصطناعي" | 1080×1350 لكل شريحة |

## الرسوم والباترنات

كل قالب فيه: نقطة/شبكة خلفية خفيفة (`pat-dots` / `pat-grid`)، شكل دائري ناعم (`blob`) خلف العنوان لعمق
بصري، ورسمة SVG معبّرة مرسومة يدويًا (روبوت، شخصية متأملة، فقاعة ضبابية، لافتة اتجاهات، قائمة تدقيق،
جرس، عدسة بحث، فقاعتا حوار) بنفس درجتي الأزرق والأسود — كلها مدمجة داخل كل ملف HTML مباشرة (مو صور
خارجية) عشان تشتغل فورًا بدون إنترنت ولا تنكسر لو انتقل الملف لمكان ثاني.

لإضافة رسمة جديدة: افتح `assets/icon-defs.svg` كمرجع، انسخ أي `<symbol>` منه إلى داخل `<defs>` في
الملف اللي تشتغل عليه، واستدعها بـ `<use href="#sym-الاسم">`. الألوان تتبع تلقائيًا (`--ink`, `--blue`,
`--paper`) سواء الخلفية فاتحة أو غامقة.

## كيف تصدّر منشور فعلي (PNG)

1. افتح أي ملف HTML في المتصفح (Chrome يعطي أدق نتيجة).
2. افتح أدوات المطوّر (F12) → في التبويب Elements حدد أي عنصر بكلاس `canvas`.
3. كليك يمين على العنصر في شجرة الـ HTML → **Capture node screenshot**.
   ستنزل صورة PNG بمقاسها الحقيقي (1080×1350 أو 1080×1080 أو 1080×1920) جاهزة للرفع مباشرة.

بديل أسرع: انسخ الملف الذي تبيه، عدّل النص داخل كل `<div class="canvas ...">` مباشرة، ثم كرر خطوة اللقطة.

## تعديل النصوص لمنشور جديد

كل شريحة/منشور مستقل داخل `<div class="canvas ...">...</div>`. غيّر النص فقط — لا تغيّر أسماء الكلاسات
(`headline`, `sub`, `fix-box`, إلخ) حتى يبقى التنسيق والمسافات كما هي تلقائيًا.

- العنوان الكبير دائمًا داخل كلاس يحتوي `headline`.
- التلوين الأزرق للشعار محصور بـ `.dot-ai` — لا تلوّن أي نص آخر.
- الخلفية الغامقة (`Blue Deep`) تُضاف بإضافة كلاس `dark` على عنصر الـ `canvas` نفسه.

## القاعدة الوحيدة اللي ما تتغير

الأزرق (`#2E6C99`) يظهر بحدود: كلمة، رقم، أو تاق — أبدًا خلفية لفقرة كاملة. هذا هو الفرق بين نظام
هوية متماسك ومنشورات متفرقة الشكل.
